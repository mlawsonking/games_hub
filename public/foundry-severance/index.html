A turn-based roguelike: you are a maintenance robot waking inside a factory that sealed its doors and severed its staff nineteen years ago.

About

You come back online in Maren's workshop in Gatetown, a shanty grown against the factory wall. The bench is cold and the door is open.

Every move is a turn. Search, pick up what the heaps give you, fit it to your paper doll, and watch integrity and charge. Saves live in the game's own storage, and the in-game export writes them to a file.

What the frame allows

  • allow-scripts The game is JavaScript.
  • allow-same-origin Gives the game its own origin (never the hub's) so its saves in localStorage work.
  • allow-pointer-lock Kept from the reviewed base set the game was first framed with. Not used today and harmless.
  • allow-downloads The save export writes a JSON file through an <a download> click. Without it that silently fails inside the frame.

Everything else is off: no pop-ups, no dialogs, no navigating this page. The game never sees this hub's address.
