About

The Tidepool sea again, but now you fish it. Three tools each catch a different kind of creature and breed the opposite trait: the Net breeds speed, the Lure breeds guile, the Jolt breeds nerve. Lean on one and the pool's other flanks open.

A run lasts three and a half minutes. Each tide you draft one of three powers. Push a trait to its corner to trigger a bloom, then cash the flanks it left open. There is a daily challenge with a shared seed.

What the frame allows

  • allow-scripts The game is one HTML file with an inline script. It keeps nothing in storage, so it runs in an opaque origin without allow-same-origin.
  • allow="clipboard-write" The end screen's Copy result button writes the run summary to the clipboard. Without this permission the copy is blocked, though the button still says Copied.

Everything else is off: no pop-ups, no dialogs, no navigating this page. The game never sees this hub's address.
